# NEXUS MESSENGER

Веб-мессенджер реального времени с поддержкой чатов, личных сообщений и админ-панелью.

## 🚀 Возможности

- **Чат в реальном времени** - обмен сообщениями через WebSocket
- **Личные сообщения** - приватная переписка между пользователями
- **Аутентификация** - регистрация, вход, верификация по email
- **Профили пользователей** - аватары, статусы, информация о пользователе
- **Админ-панель** - управление пользователями, модерация сообщений
- **Адаптивный дизайн** - работа на десктопных и мобильных устройствах

## 📋 Требования

- Python 3.8+
- Flask
- Flask-SQLAlchemy
- Flask-SocketIO
- Flask-Login
- Flask-Mail
- Werkzeug

## ⚙️ Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <project-directory>
```

2. Установите зависимости:
```bash
pip install flask flask-sqlalchemy flask-socketio flask-login flask-mail werkzeug
```

3. Настройте переменные окружения в файле `admin_utils/const.py`:
- `SECRET_KEY` - секретный ключ приложения
- `SQLALCHEMY_DATABASE_URI` - URI базы данных
- `MAIL_SERVER`, `MAIL_PORT` - настройки SMTP сервера
- `MAIL_USERNAME`, `MAIL_PASSWORD` - учётные данные почты

4. Запустите приложение:
```bash
python main.py
```

5. Откройте браузер и перейдите по адресу:
```
http://127.0.0.1:8080
```

## 🔧 Конфигурация

### База данных

Приложение использует SQLAlchemy для работы с базой данных. Поддерживаются различные СУБД:
- SQLite (по умолчанию)
- PostgreSQL
- MySQL

### Email рассылка

Для верификации пользователей настроена отправка email через SMTP:
```python
MAIL_SERVER = 'smtp.example.com'
MAIL_PORT = 587
MAIL_USERNAME = 'your@email.com'
MAIL_PASSWORD = 'your-password'
```

### WebSocket

SocketIO настроен для работы в режиме реального времени:
- Ping interval: 25 секунд
- Ping timeout: 60 секунд
- CORS разрешён для всех источников

## 👤 Роли пользователей

- **Гость** - может просмотреть страницу входа/регистрации
- **Пользователь** - полный доступ к чату, личным сообщениям, профилю
- **Администратор** - доступ к админ-панели, управление пользователями и сообщениями

## 🛡️ Безопасность

- Хеширование паролей через Werkzeug
- Верификация email при регистрации
- Защита маршрутов через Flask-Login
- Админ-доступ через декоратор `@admin_required`
- Сессионные куки с таймаутом 7 дней

## 📝 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/users` | Получить список пользователей |
| POST | `/api/message/send` | Отправить сообщение |
| GET | `/api/profile/<user_id>` | Получить профиль пользователя |

## 🔌 WebSocket события

### Общие чаты
- `send_message` - отправка сообщения
- `receive_message` - получение сообщения
- `typing` - индикатор набора текста

### Личные сообщения
- `private_message` - отправка личного сообщения
- `private_typing` - индикатор набора в личном чате

## 🧩 Расширения

- **Flask-SQLAlchemy** - ORM для работы с БД
- **Flask-SocketIO** - WebSocket поддержка
